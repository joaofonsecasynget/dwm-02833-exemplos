# Aula 11 — tabelas

Ficheiros de partida dos exercícios da aula 11. Copia a pasta `aula-11` inteira (com a pasta `img`, usada no exercício 7) para a pasta `aulas/` do teu repositório `dwm-02833` (ou para Documentos), resolve os exercícios e abre cada ficheiro com o Live Server.

Cada ficheiro tem no `head` a linha `<style>td, th { border: 1px solid; }</style>`: só desenha as linhas da tabela. Deixa-a ficar; vais aprender o que faz no bloco de CSS.

| Ficheiro | Exercício | Tipo |
|---|---|---|
| `exercicio-1.html` | 1 · prevê o resultado (linhas e colunas) | obrigatório |
| `exercicio-2.html` | 2 · completa a tabela (tr e td) | obrigatório |
| `exercicio-3.html` | 3 · altera para cabeçalhos (th) | obrigatório |
| `exercicio-4.html` | 4 · acrescenta uma coluna | obrigatório |
| `exercicio-5.html` | 5 · escreve de raiz uma tabela | obrigatório |
| `exercicio-6.html` | 6 · dá um título à tabela (caption, validada no W3C) | opcional |
| `exercicio-7.html` | 7 · imagens e ligações numa tabela | opcional |

Faz primeiro os obrigatórios; os opcionais são para quando acabares. As soluções estão na apresentação da aula, no diapositivo a seguir a cada exercício.

**Entregar:** põe a pasta `aula-11` dentro de `aulas/` no teu `dwm-02833`, pelo site do GitHub (Add file → Upload files) ou pelo VS Code (commit e Sync Changes), como preferires.
