# Aula 8 — conclui as páginas do projeto

Aula de consolidação: não há exercícios novos. O exemplo resolvido é o site do Clube de Atletismo da Vila na pasta [`projeto/`](../projeto/).

Lista de verificação da atividade:

1. Um ficheiro `.html` por cada página do mapa do site, com o nome certo (`index.html` para a inicial).
2. Em cada página, a estrutura completa: `header`, `nav`, `main` (com pelo menos uma `section`) e `footer`.
3. O `header`, o `nav` e o `footer` iguais em todas as páginas — só o `main` muda.
4. Todos os links do menu, em todas as páginas, abrem a página certa.
5. Cada página validada no W3C (https://validator.w3.org/), sem erros.
6. O trabalho em `projeto/` no repositório `dwm-02833`, com commit e push.

Para o Git e o GitHub, segue o [GUIA.md](../GUIA.md).
