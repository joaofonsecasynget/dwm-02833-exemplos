# Aula 10 — hiperligações e imagens

Ficheiros de partida dos exercícios da aula 10. Copia a pasta `aula-10` inteira, **com a pasta `img`**, para a pasta `aulas/` do teu repositório `dwm-02833` (ou para Documentos), resolve os exercícios e abre cada ficheiro com o Live Server. Sem a pasta `img`, as imagens não aparecem.

| Ficheiro | Exercício | Tipo |
|---|---|---|
| `exercicio-1.html` | 1 · prevê o resultado (ligações para outros sites) | obrigatório |
| `exercicio-2.html` e `contactos.html` | 2 · completa o href (ligação para outra página) | obrigatório |
| `exercicio-3.html` | 3 · completa a imagem (src e alt) | obrigatório |
| `exercicio-4.html` | 4 · altera a imagem | obrigatório |
| `exercicio-5.html` | 5 · escreve de raiz (título, imagem e ligação) | obrigatório |
| `exercicio-6.html` | 6 · o sol que é hiperligação | opcional |
| `dia.html` e `noite.html` | 7 · dia e noite, duas páginas ligadas | opcional |
| `img/` | as imagens `sol.png`, `lua.png` e `arvore.png` | — |

Faz primeiro os obrigatórios; os opcionais são para quando acabares. As soluções estão na apresentação da aula, no diapositivo a seguir a cada exercício.

**Entregar:** põe a pasta `aula-10` (com a pasta `img`) dentro de `aulas/` no teu `dwm-02833`, pelo site do GitHub (Add file → Upload files) ou pelo VS Code (commit e Sync Changes), como preferires.
