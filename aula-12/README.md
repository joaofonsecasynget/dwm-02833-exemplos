# Aula 12 — formulários

Ficheiros de partida dos exercícios da aula 12. Já estão na pasta `aulas/aula-12` do teu repositório `dwm-02833`: no VS Code carrega em Sync Changes (ou faz Pull) ou, no github.com, recarrega a página do repositório. Abre a pasta `aulas/aula-12` (File → Open Folder), resolve os exercícios e vê o resultado de cada ficheiro com o Live Server. Quem não tiver o repositório clonado descarrega o ZIP deste repositório de exemplos e copia a pasta `aula-12` para Documentos.

Os formulários desta aula não têm `action`: ao carregares no botão, a página recarrega-se e o endereço (URL) passa a mostrar os dados enviados, por exemplo `?nome=Rita`. É assim que vês o que o formulário envia.

| Ficheiro | Exercício | Tipo |
|---|---|---|
| `exercicio-1.html` | 1 · prevê o resultado (form, input, name e botão) | obrigatório |
| `exercicio-2.html` | 2 · completa as etiquetas (label, for e id) | obrigatório |
| `exercicio-3.html` | 3 · altera os tipos dos campos (email, number, password) | obrigatório |
| `exercicio-4.html` | 4 · completa a validação (required, min, max e maxlength) | obrigatório |
| `exercicio-5.html` | 5 · escreve de raiz um formulário de inscrição | obrigatório |
| `exercicio-6.html` | 6 · escolhe uma opção numa lista (select e option) | opcional |
| `exercicio-7.html` | 7 · botões de opção e caixas de seleção (radio e checkbox) | opcional |

Faz primeiro os obrigatórios; os opcionais são para quando acabares. As soluções estão na apresentação da aula, no diapositivo a seguir a cada exercício.

**Entregar:** guarda os ficheiros em `aulas/aula-12` do teu `dwm-02833`, pelo VS Code (commit e Sync Changes) ou pelo site do GitHub (Add file → Upload files), como preferires.
