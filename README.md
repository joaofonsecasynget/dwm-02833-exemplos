# dwm-02833-exemplos — Desenvolvimento Web e Móvel (10ºDS)

Exemplos do professor da UC02833 Conceber aplicações para a web na vertente frontend, mostrados nas aulas. É público: qualquer aluno pode consultar e clonar.

**Começa pelo [GUIA.md](GUIA.md)** (também em [PDF](GUIA.pdf)): tem os passos para criares a conta no GitHub e o teu repositório `dwm-02833`, instalares e configurares o Git e o VS Code, e trabalhares com commit, push e pull no VS Code.

A estrutura é a mesma que se pede no repositório de cada aluno: `projeto/` com o site (`index.html`, `css/`, `js/`, `img/`) e `fichas/` com as fichas do Projeto Web.

## Conteúdo

| Pasta | O que tem |
|---|---|
| [`aula-01/`](aula-01/) | Respostas do diagnóstico, do aquecimento e dos três pilares; `exemplo.html` (com `exemplo.js`) para dissecar com as ferramentas de programador (F12) |
| [`aula-02/`](aula-02/) | Solução da atividade 1, a primeira página (`index.html`), e a extensão (`sobre.html`); respostas do aquecimento |
| [`aula-03/`](aula-03/) | `aula3.txt` com as respostas: blocos da página, do telemóvel ao computador, exemplo de exit ticket |
| [`aula-04/`](aula-04/) | `aula4.txt` com as respostas: tecnologias, revisão do bloco e exemplos de autoavaliação |
| [`aula-07/`](aula-07/) | Soluções dos exercícios 1 a 4 sobre estrutura semântica e navegação, com as extensões |
| [`fichas/`](fichas/) | Exemplo resolvido das fichas 0 e 1 e dos wireframes do Projeto Web, para o cliente fictício Clube de Atletismo da Vila |
| [`projeto/`](projeto/) | O site do Clube de Atletismo da Vila: uma página `.html` por cada página do mapa do site, com `header`, `nav`, `main` e `footer` e a navegação entre todas — a solução da atividade da aula 7. Cresce com as aulas seguintes (CSS, JavaScript) |

As aulas 5 e 6 foram de preparação do ambiente (GitHub, Git e VS Code): os passos estão no [GUIA.md](GUIA.md).
