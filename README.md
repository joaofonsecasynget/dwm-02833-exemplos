# dwm-02833-exemplos — Desenvolvimento Web e Móvel (10ºDS)

Exemplos do professor da UC02833 Conceber aplicações para a web na vertente frontend, mostrados nas aulas. É público: qualquer aluno pode consultar e clonar.

**Começa pelo [GUIA.md](GUIA.md)** (também em [PDF](GUIA.pdf)): tem os passos para criares a conta no GitHub e o teu repositório `dwm-02833`, instalares e configurares o Git e o VS Code, e trabalhares com commit, push e pull no VS Code.

A estrutura é a mesma que se pede no repositório de cada aluno: `projeto/` com o site (`index.html`, `css/`, `js/`, `img/`) e `fichas/` com as fichas do Projeto Web.

## Como usar este repositório

Este repositório mostra **o que deve estar no teu**. Compara-o com o teu `dwm-02833`:

| No teu repositório | O que deve ter | Exemplo aqui |
|---|---|---|
| `fichas/` | a **ficha 1** do teu projeto (brief e mapa do site, em Word) e os **wireframes** de todas as páginas (PowerPoint) | [`fichas/`](fichas/) — as fichas e os wireframes do Clube de Atletismo da Vila |
| `projeto/` | o teu site: um ficheiro `.html` por cada página do teu mapa do site (a primeira é `index.html`), todas com `header`, `nav`, `main` e `footer` e com o menu a ligar todas as páginas; e as pastas `css/`, `js/` e `img/` | [`projeto/`](projeto/) — o site do Clube de Atletismo da Vila |

O teu projeto é **o do teu cliente**, não o do Clube de Atletismo da Vila: usa o exemplo para perceberes a estrutura e o que se pede, não para o copiares. As pastas `aula-NN` têm as soluções dos exercícios das aulas, para confirmares as tuas respostas; não é preciso copiá-las para o teu repositório.

Para veres o exemplo a funcionar: clona este repositório no VS Code (`https://github.com/joaofonsecasynget/dwm-02833-exemplos.git`), abre `projeto/index.html` com o Live Server e clica nos links do menu. A lista de verificação do que deve estar pronto está em [`aula-08/README.md`](aula-08/README.md).
