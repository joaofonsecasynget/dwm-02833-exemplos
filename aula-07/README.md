# Aula 7 — estrutura semântica e navegação entre páginas

| Ficheiro | Exercício |
|---|---|
| `exercicio-1.html` | 1 · prevê o resultado (com a extensão: link Contactos) |
| `exercicio-2.html` | 2 · completa a secção (com a extensão: terceiro produto) |
| `exercicio-3.html` | 3 · monta a página completa (com a extensão: segundo link no footer) |
| `exercicio-4-sobre.html` | 4 · liga as páginas |
| `exercicio-4-contactos.html` | 4 · extensão: o nav de contactos.html |

**Atividade: cria as páginas do teu projeto** — o exemplo resolvido é o site do Clube de Atletismo da Vila na pasta [`projeto/`](../projeto/): uma página `.html` por cada página do mapa do site da ficha 1, todas com o mesmo `header`, `nav` e `footer`, e só o `main` a mudar.

Os links dos exercícios 1, 3 e 4 apontam para páginas que não existem nesta pasta: ao clicar, o Live Server mostra «Cannot GET» — é o 404 da aula 1.
