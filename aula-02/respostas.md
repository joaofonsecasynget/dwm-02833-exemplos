# Aula 2 — respostas

## Aquecimento

1. Estrutura → **HTML**.
2. Quem responde ao pedido do browser → **o servidor**.
3. Página inexistente → **404**.

## Atividade 1: a minha primeira página

Solução em `index.html`, com `title`, `h1`, `h2`, dois `p`, uma lista com três `li`, uma imagem com `src` e `alt` e uma ligação externa. A extensão é `sobre.html`, ligada nos dois sentidos. O tema e os textos variam de aluno para aluno.

Para validar: abre https://validator.w3.org/#validate_by_input, cola o código e carrega em Check — não deve aparecer nenhum erro.
